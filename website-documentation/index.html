How it came together

A scrapped version got a second life

To create this page, I took an old HTML/CSS page I had for my old portfolio website from around 2024 (no longer active since i no longer work in that industry) That site went through like 4 different iterations before i landed on the final one, the one i am reusing here with some edits is an old scrapped version. I used my old sidebar script, which i converted to its own JS file a few weeks ago, tweaked the CSS to match the homepage, and the rest was history. The original homepage was made from scratch, with some assistance from Claude at the time. (I refuse to pay 20$ a month now!!!!)

I actually host all of my projects for this course on the same GitHub repo in order to already have them available to attach to this portfolio site with little effort.

Visual overview

A familiar dark workspace

The visual choices are meant to make the work easy to browse, while letting each project bring its own personality.

Dark gray and bright blue

The colors borrow from the VS Code interface: deep gray surfaces with blue accents. I like the familiar feel, and the blue gives links and section details enough contrast to stand out.

Sidebar stays handy

The navigation sits in a sidebar so the different projects stay easy to reach as the portfolio grows. On smaller screens it shifts into a compact row of links.

AaClear headings
Readable project notes

Simple type, distinct projects

Poppins gives the site a little character, while the straightforward headings and card layouts keep the project descriptions readable. The work itself supplies most of the color and visual variety.

Reflection

Reuse, then make it feel like mine

Honestly, reusing the old site made this come together faster, but it still needed a fair bit of cleanup. The sidebar was already something I liked, so pulling it into its own JS file made it easy to use across pages instead of copying navigation everywhere. I kept the dark panels and bright blue highlights because they feel familiar to me from working in VS Code, and the contrast makes the text and links easy to pick out. The rounded cards give each project a clear home without making the page feel like a pile of raw links. The project images do most of the colorful work, so the interface can stay simple and let each piece be the focus.

Keeping the coursework in one GitHub repo has been convenient too. I can connect each project to the portfolio without moving it to another place or maintaining a separate site for every assignment. The portfolio is growing along with the work, and reusing the old structure lets me spend more time on what each project says and shows.
