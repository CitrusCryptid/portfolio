How I put this website together

To create this page, I took an old HTML/CSS page I had for my old portfolio website from around 2024 (no longer active since i no longer work in that industry) That site went through like 4 different iterations before i landed on the final one, the one i am reusing here with some edits is an old scrapped version. I used my old sidebar script, which i converted to its own JS file a few weeks ago, tweaked the CSS to match the homepage, and the rest was history. The original homepage was made from scratch, with some assistance from Claude at the time. (I refuse to pay 20$ a month now!!!!)

I actually host all of my projects for this course on the same GitHub repo in order to already have them available to attach to this portfolio site with little effort.

The design

The site is mostly dark gray with blue accents. I kept those colors because they were already in the old version, and I like how links and headings stand out against the darker background. The font is Poppins; it was already part of the project and still works well for the headings and descriptions.

The sidebar keeps all the course pages in one place, which matters now that there are a lot of them. I’ve added thumbnails to the project list using images from the work itself, so you can get a quick idea of each project before opening it.

Looking back

Honestly, having an old version to reuse saved me time, but it still needed work. It wasn’t a finished template I could just drop in. I had to clean up the content, make the sidebar work across the pages, and change the styling to fit the projects I’m doing now. It was easier than starting over, and I still got to make it feel like my site.

Keeping the class projects in one GitHub repo has helped too. The files are already in the same place, so adding them to the portfolio is pretty straightforward. I don’t have to set up and maintain a separate site for each assignment.
